Appendix A: Library Reference

[Back to Contents]

Every routine in the book, by file. Inputs are registers; “destroys” lists what the caller must not rely on.

gfx.asm: the basics (Chapter 1, 2)

RoutineInputDoes
wait_vblank—Returns at the start of the next VBlank
lcd_off—Waits for VBlank, then switches the LCD off
lcd_on—Switches the LCD on (background, sprites, $8000 tiles)
copy_bytesHL source, DE destination, BC countCopies memory
fill_bytesHL destination, BC count, A valueFills memory
fill_mapA tileFills the whole background map
map_addrB column, C rowHL = address in the background map (destroys DE)
set_tileA tile, B column, C rowWrites one map entry
set_paletteA shadesSets rBGP, rOBP0 and rOBP1

canvas.asm: pixels, lines, shapes (Chapters 3–5)

RoutineInputDoes
canvas_clearA colourFills the canvas
plotB x, C y, D colourSets one pixel (ignored if off the canvas)
toggle_pixelB x, C yInverts one pixel
draw_hline, draw_vlineB x, C y, D colour, E lengthStraight line
draw_lineB x0, C y0, D x1, E y1; wColourAny line (Bresenham)
draw_rect, fill_rectB x, C y, D width, E height; wColourRectangle outline or solid
draw_circle, fill_circleB cx, C cy, E radius; wColourCircle outline or solid
canvas_map—Lays tiles 0–255 on the map as a 16×16 block at column 2, row 1
canvas_to_vram—Copies the canvas to tile memory (LCD off)

tilemap.asm: the shadow map (Chapters 4, 5)

RoutineInputDoes
shadow_fillA tileFills the RAM copy of the map
shadow_setA tile, B column, C rowWrites one entry
shadow_hline, shadow_vlineA tile, B column, C row, E lengthA line of tiles
flood_fillA new tile, B column, C rowReplaces a connected region of one tile with another
shadow_to_vram—Copies the shadow map to the real map (LCD off)

oam.asm: sprites (Chapter 6)

RoutineInputDoes
oam_init—Copies the DMA routine to HRAM and hides all sprites (oam_clear alone only hides them)
oam_begin, oam_end—Start a frame's sprite list; hide the unused entries
oam_addB x, C y, D tile, E flagsAdds one sprite (screen coordinates)
draw_metaspriteHL definition, B x, C yAdds a group of sprites
hOAMDMA—Copies the shadow OAM to OAM (call in VBlank)

scroll.asm: scrolling (Chapter 7)

RoutineInputDoes
stream_columnA world columnWrites that column of the one-dimensional world into the background map
stream_world_columnA column, B first rowWrites 19 tiles of the 64×64 world down a map column
stream_world_rowA row, B first columnWrites 21 tiles of the 64×64 world along a map row

text.asm: text (Chapter 8)

RoutineInputDoes
text_init—Loads the font as tiles $20–$7F (LCD off)
text_window, text_background—Choose which map text goes to
print_atB column, C rowMoves the cursor
print_charA characterPrints one character (safe with the LCD on)
print_stringHL zero-terminated stringPrints a string
print_numberA 0–255Prints three digits

vblank.asm: frames and queues (Chapter 9)

RoutineInputDoes
vblank_init—Enables the VBlank interrupt in rIE; the program must then execute EI
wait_frame—Sleeps until the next frame begins
queue_tileA tile, B column, C rowQueues a map change for VBlank
queue_numberA 0–255, B column, C rowQueues three digit tiles

joypad.asm: input (Chapter 11)

RoutineInputDoes
read_joypad—Updates wJoy (held) and wJoyNew (newly pressed); A = wJoy

cgb.asm: Game Boy Color (Chapter 10)

RoutineInputDoes
hdma_copyHL source (16-aligned), DE VRAM destination, B blocks of 16Copies by hardware; the CPU waits

fast.asm: speed (Chapter 10)

RoutineInputDoes
copy_unrolledHL source, DE destination, B blocks of 166 cycles per byte
copy_stackHL source, DE destination, B blocks of 164.5 cycles per byte; leaves interrupts off
fill_stackHL end address, D blocks of 16, A value2 cycles per byte; leaves interrupts off
map_addr_fastB column, C rowHL = background map address

Appendix B: Graphics Registers

[Back to Contents]
RegisterAddressPurpose
rLCDC$FF40Bit 7 LCD on; 6 window map at $9C00; 5 window on; 4 tiles from $8000; 3 background map at $9C00; 2 sprites 8×16; 1 sprites on; 0 background on
rSTAT$FF41Bits 1–0 current LCD mode (mode 3: VRAM and OAM locked; mode 2: OAM locked); bit 6 interrupt on LY = LYC
rSCY, rSCX$FF42, $FF43Background scroll
rP1$FF00Joypad: write bit 4 or 5 low to select a group, read bits 3–0 (0 = pressed)
rLY$FF44Line being drawn: 0–143 visible, 144–153 VBlank
rLYC$FF45Line to compare with rLY
rDMA$FF46Write a high byte to copy $XX00-$XX9F to OAM
rBGP$FF47Background shades
rOBP0, rOBP1$FF48, $FF49Sprite shades
rWY, rWX$FF4A, $FF4BWindow position (WX is the column plus 7)
rIE, rIF$FFFF, $FF0FInterrupts enabled / pending: bit 0 VBlank, bit 1 STAT
rDIV$FF04Counts up every 64 machine cycles; any write resets it
rVBK$FF4F(Colour) Selects VRAM bank 0 or 1
rHDMA1–rHDMA5$FF51–$FF55(Colour) Hardware copy: source, destination, length and start
rBCPS, rBCPD$FF68, $FF69(Colour) Background palette index and data
rOCPS, rOCPD$FF6A, $FF6B(Colour) Sprite palette index and data
