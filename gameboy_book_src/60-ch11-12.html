Let's tie everything together with a complete, assembler-ready program that counts from 0 to 20, displays each value, and verifies the final count. Save this as counter.asm:

[[file counter.asm]]

Assemble and run:

[[text]] rgbasm -I . -o counter.o counter.asm && rgblink -o counter.gb counter.o && rgbfix -v -p 0xFF counter.gb && mgba counter.gb [[/text]]

The Game Boy's screen is only 20 characters wide, so the row of numbers wraps onto the next line. The counter lives in register C the whole time: print_number promises to keep BC safe, which is why this program works.

This program demonstrates register operations, subroutine calls and returns, loops with manual construction, comparison and conditional jumps, the stack for preserving values, and—crucially—debug output to verify that the code is working correctly.

12. RST Instructions & Library Routines

[Back to Contents]

Throughout this guide you've been using RST $10 without much explanation. This chapter explains what it is: one of the CPU's built-in shortcut instructions. It also lists the library routines and hardware registers behind the examples in this guide.

RST (Restart) Instructions

The CPU has a set of special single-byte CALL instructions called RST (Restart). Where a normal CALL takes 3 bytes (the opcode plus a 2-byte address), an RST takes just 1 byte. The CPU pushes the current PC onto the stack and jumps to a fixed address, exactly like a CALL. When the routine hits RET, execution returns to where you left off.

Think of them as built-in function calls — shorthand for the most commonly used routines. The Game Boy has no operating system, and the first $100 bytes of your cartridge are yours, so you decide what each RST does. This guide's debug library puts a JP print_char at $0010, which is why RST $10 prints a character.

The pattern is always the same: load registers with the values the routine expects, then execute the RST or CALL. It's the assembly equivalent of calling a library function.

The RST Table

There are exactly 8 RST instructions. Each jumps to a fixed address that is a multiple of 8:

Instruction Jumps To Bytes Game Boy Purpose
RST $00 $0000 1 Free for your use (the boot ROM starts at $0000 only until it hands over to $0100)
RST $08 $0008 1 Free for your use
RST $10 $0010 1 Print character in A (set up by this guide's debug library)
RST $18 $0018 1 Free for your use
RST $20 $0020 1 Free for your use
RST $28 $0028 1 Free for your use (many games put a jump-table routine here)
RST $30 $0030 1 Free for your use
RST $38 $0038 1 Free for your use. Often made a crash trap, because the byte $FF (blank ROM, and the padding rgbfix adds) is the opcode for RST $38

The most commonly used here is RST $10 — this guide's workhorse print routine. Almost every program that displays text uses it. Note that the five interrupt handlers sit just above the RST area, at $0040, $0048, $0050, $0058 and $0060, so the RST slots have only 8 bytes each before the next one begins.

Common Library Routines

Besides the RST entry points, you call routines with a regular CALL instruction. The Game Boy has no built-in routines, but our debug library supplies the most useful ones. Here they are, together with the hardware registers behind the button and sound examples:

Screen & Output

debug_init debug_init (none) Set up the screen: load the font, clear the display, home the cursor and switch the LCD on. Calling it again clears the screen
print_block print_block DE = address, BC = length Print string of BC bytes from DE (BC must not be 0)
set_cursor set_cursor B = row, C = column (row 0–17, column 0–19) Set print position (AT equivalent). Counted from the top left

Address Name Returns What It Does
$FF00 rP1 (joypad) Low 4 bits: 0 = pressed Write %00010000 to select A / B / Select / Start, or %00100000 to select the D-pad, then read it back (twice)

Sound

Address Name Setup What It Does

Why RST Instead of CALL?

You might wonder: if RST $10 does the same as CALL $0010, why bother with RST at all? Two reasons:

Size: RST is 1 byte, CALL is 3 bytes. In a routine that prints hundreds of characters, that's significant — a Game Boy cartridge can be as small as 32KB.

Speed: RST executes in 4 machine cycles (16 clock ticks) vs 6 machine cycles (24 clock ticks) for CALL. At about 4.19 MHz, every cycle counts in time-critical code like games.

The trade-off is that there are only 8 RST addresses available ($00, $08, $10, $18, $20, $28, $30, $38), and each has only 8 bytes of room before the next. Which routines deserve these premium slots is your choice.
