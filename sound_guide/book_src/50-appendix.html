Appendix A: Library Reference

[Back to Contents]

Every routine in the book, by file. Inputs are registers; “destroys” lists what the caller must not rely on.

sound.asm: the basics (Chapters 1, 2 and 7)

RoutineInputDoes
sound_init—Switches the sound chip off and on (clearing every register), then master volume full and every channel to both speakers
note_freqA note number 0–71DE = the 11-bit pitch value from NoteTable (destroys HL)
play_ch1, play_ch2, play_ch3DE pitch valueWrites the pitch to NRx3/NRx4 with the start bit set. Set duty and envelope first
wave_loadHL 16 bytesSwitches channel 3 off, loads wave RAM, switches it on (destroys B, DE)

notes.inc: names (Chapter 2, 10)

NamesMeaning
C2 ... B7, with Cs2 for C sharpNote numbers 0–71 (C2 = 0, A4 = 33)
REST, SONG_LOOPSpecial values in a song stream
DRUM_KICK, DRUM_SNARE, DRUM_HATDrum numbers for channel 4 in a song
N16, N8, N4, N2, N1Lengths in frames: 6, 12, 24, 48, 96

frame.asm: the frame clock (Chapter 9)

RoutineInputDoes
frame_init—Enables the VBlank interrupt in rIE; the program must then execute EI
wait_frame—Sleeps until the next frame begins
wTicks—Frames since frame_init, wrapping at 256

music.asm: the music engine (Chapter 10)

RoutineInputDoes
music_playHL songStarts the song from the beginning
music_tick—One frame of music: call once per frame, after wait_frame
music_stop—Switches the music off and silences channels 1–4
sfx_holdA framesKeeps the music off channel 1 for that long, for a sound effect

A song is DW four stream addresses (0 for an unused channel) and DB four instrument bytes. A stream is pairs of bytes: note (or REST) and length in frames, ended by SONG_LOOP. On channel 4 the note is a drum number from DrumTable.

screen.asm, gfx.asm, text.asm: the little display

RoutineInputDoes
screen_init—Loads the font, clears the screen, switches the LCD on
show_textB column, C row, HL zero-terminated stringPrints a string at a position
print_noteA note numberPrints its name, like C-4 or F#5, at the cursor
print_atB column, C rowMoves the cursor (destroys HL)
print_char, print_string, print_numberA character; HL string; A 0–255Print at the cursor (safe with the LCD on)

joypad.asm: input (Chapter 11)

RoutineInputDoes
read_joypad—Updates wJoy (held) and wJoyNew (newly pressed); A = wJoy

Appendix B: Sound Registers

RegisterAddressPurpose
rNR10$FF10Channel 1 sweep: bits 6–4 step time (n/128 s, 0 = off); bit 3 direction (1 = falling); bits 2–0 shift
rNR11, rNR21$FF11, $FF16Bits 7–6 duty (1/8, 2/8, 4/8, 6/8); bits 5–0 length: lasts (64 − length)/256 s
rNR12, rNR22, rNR42$FF12, $FF17, $FF21Envelope: bits 7–4 start volume; bit 3 rising; bits 2–0 step time in 1/64 s (0 = none). Top five bits zero switches the channel off
rNR13, rNR23, rNR33$FF13, $FF18, $FF1DPitch, low 8 bits
rNR14, rNR24, rNR34$FF14, $FF19, $FF1EBit 7 start; bit 6 stop when the length runs out; bits 2–0 pitch, high 3 bits. Channels 1–2: 131072 / (2048 − x) Hz; channel 3: 65536 / (2048 − x) Hz
rNR30$FF1ABit 7: channel 3 on
rNR31$FF1BChannel 3 length: lasts (256 − length)/256 s
rNR32$FF1CChannel 3 volume, bits 6–5: 0 silent, 1 full, 2 half, 3 a quarter
rWAVE$FF30–$FF3FWave RAM: 32 four-bit samples, high four bits first. Change it with channel 3 off
rNR41$FF20Channel 4 length, bits 5–0
rNR43$FF22Noise: bits 7–4 shift s; bit 3 width (1 = 7-bit, buzzy); bits 2–0 divisor r. Clock 262144 / (r × 2s) Hz
rNR44$FF23Bit 7 start; bit 6 stop when the length runs out
rNR50$FF24Master volume: bits 6–4 left, bits 2–0 right (0–7)
rNR51$FF25Panning: bits 7–4 channels 4–1 to the left, bits 3–0 channels 4–1 to the right
rNR52$FF26Bit 7 sound on. Switching it off clears every sound register. Bits 3–0 (read): channels 4–1 are playing
